SAKSHI BEHL — LANDING PAGE
==========================

TO GO LIVE
1. Upload this whole folder to any static host (Netlify / Vercel / GitHub Pages — all free).
   Drag-and-drop the folder at https://app.netlify.com/drop for the fastest route.
2. Point a custom domain at it if you buy one (e.g. sakshibehl.in), then put the URL in her IG bio.
3. In index.html, replace the og:image relative path with the full live URL (one marked comment in <head>).

MONTHLY STATS UPDATE
Edit stats.json — four numbers + the footnote line. No HTML edits needed.

REELS (when you have the MP4s)
Compress each to 720p and drop them in this folder named reel-1.mp4 … reel-4.mp4.
They will autoplay in the Recent Work tiles automatically. Optional: add poster="cover-N.jpg"
to each <video> tag for instant paint.

SWAPPING PHOTOS
Replace the .jpg files keeping the same names, or edit the <img> tags. The hero photo
should be shot against a light wall (it uses a blend treatment); others can be anything.
